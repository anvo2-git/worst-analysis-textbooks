# The Worst Analysis Textbooks

A collection of 25 HTML+CSS landing page iterations for a semi-sarcastic site showcasing "The Worst Analysis Textbooks" — featuring fake user reviews of terrible math/real analysis textbooks.

## Tech Stack
- **Pure HTML and CSS only**
- No JavaScript frameworks, no external APIs, no build tools, no data persistence
- Static site deployed on Vercel via GitHub

## Project Structure
- `index.html` — Gallery page at root, tells the story of the design process
- `v1/` through `v25/` — Each folder contains one landing page iteration (`index.html` + `style.css`)

## Design Direction
- Semi-sarcastic, dark humor tone
- Bold typography
- Each version should have: site title/tagline, fake textbook entries with titles, authors, ratings, and sarcastic review quotes
- v1–v12: Wildly different explorations (go wide)
- v13–v19: Combining favorites (narrow down)
- v20–v25: Refining toward a final design (polish)

## Rules
- No JS — pure HTML+CSS only
- No external dependencies or CDNs
- Each version is self-contained in its own folder
- Keep CSS in a separate style.css file per version
